# 客户机会阶段

| 阶段 | 进入证据 |
|---|---|
| 线索 | 有明确组织或联系人 |
| 需求确认 | 客户问题、场景和预期结果得到确认 |
| 方案设计 | 双方正在形成范围、方案或验证路径 |
| 预算/立项 | 预算来源、立项路径或采购机制得到确认 |
| 试点/验证 | 有试点范围、责任人、时间和验收标准 |
| 商务推进 | 价格、合同、采购或合作协议进入处理 |
| 赢单 | 已签署或收到正式采购依据 |
| 暂停/丢单 | 有明确暂停、失败或停止投入的证据 |

健康度使用红黄绿，并记录证据：

- 绿：关键人、问题、下一步和时间均明确，近期有双向推进。
- 黄：存在一个重要缺口或行动可能延期。
- 红：关键前提缺失、承诺持续未闭环、两周无有效推进或出现明确否定信号。

不得只根据主观信心或聊天热度判断健康度。
