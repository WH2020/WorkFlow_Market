## 📝 技术亮点

1. **确定性设计**：所有规则均为纯函数，相同输入保证相同输出
2. **零外部依赖**：纯Python标准库实现，无安全风险
3. **可扩展架构**：新规则只需继承SignalRule并实现evaluate()
4. **用户反馈闭环**：采纳率追踪支持持续优化
5. **硬审批边界**：所有组件只提供建议，不自动执行
