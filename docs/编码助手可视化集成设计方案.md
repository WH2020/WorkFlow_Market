# 编码助手可视化集成设计方案

## 目标

在 Agent4Market 桌面工作台的可视化界面中嵌入 Claude Code 和 Codex CLI 的能力，让用户无需切换到终端或 IDE，即可在 Web 界面中使用自然语言对话创建和跟踪任务。

## 设计原则

1. **保持架构一致性**：继续使用桥接层 `python -m agent_platform coding-agent ...`，不绕过现有审批机制
2. **渐进式增强**：现有命令行入口继续可用，Web 界面作为额外选项
3. **视觉一致性**：遵循现有工作台的设计语言和交互模式
4. **权限边界清晰**：在界面明确标注哪些操作需要在任务中心审批

async function loadAssistantStatus() {
  try {
    const response = await fetch("/api/coding-agent/doctor");
    const data = await response.json();

    }
  } catch (error) {
    $("assistant-status").textContent = "连接失败";
    $("assistant-status").className = "period-badge error";
  }

// 发送消息
$("assistant-send")?.addEventListener("click", async () => {
  const input = $("assistant-input");
  const userMessage = input.value.trim();
  if (!userMessage) return;

  // 添加用户消息
  addAssistantMessage("user", userMessage);
  input.value = "";
  input.style.height = "60px";

  // 显示输入中状态
  showAssistantTyping();

  try {
    // 调用桥接层处理消息
    const response = await fetch("/api/coding-agent/chat", {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({ message: userMessage, context: assistantState }),
    });

    const data = await response.json();
    hideAssistantTyping();

    if (data.status === "ok") {
      // 添加助手回复
      addAssistantMessage("assistant", data.reply, data.actions);

      // 更新任务ID
      if (data.task_id) {
        assistantState.currentTaskId = data.task_id;
      }
    } else {
      addAssistantMessage("assistant", `处理失败：${data.error}`, null);
    }
  } catch (error) {
    hideAssistantTyping();
    addAssistantMessage("assistant", `网络错误：${error.message}`, null);
  }
});

// 添加消息到对话
function addAssistantMessage(role, content, actions) {
  const conversation = $("assistant-conversation");

  // 移除欢迎消息
  const welcome = conversation.querySelector(".assistant-welcome");
  if (welcome) welcome.remove();

  const message = document.createElement("div");
  message.className = `assistant-message ${role}`;

  const avatar = document.createElement("div");
  avatar.className = "assistant-message-avatar";
  avatar.textContent = role === "user" ? "你" : "AI";

  const messageContent = document.createElement("div");
  messageContent.className = "assistant-message-content";
  messageContent.innerHTML = formatAssistantMessage(content);

  // 添加操作按钮
  if (actions && actions.length > 0) {
    const actionsDiv = document.createElement("div");
    actionsDiv.className = "assistant-message-actions";
    actions.forEach(action => {
      const btn = document.createElement("button");
      btn.className = action.primary ? "primary small" : "secondary small";
      btn.textContent = action.label;
      btn.onclick = () => handleAssistantAction(action);
      actionsDiv.appendChild(btn);
    });
    messageContent.appendChild(actionsDiv);
  }

  message.appendChild(avatar);
  message.appendChild(messageContent);
  conversation.appendChild(message);

  // 滚动到底部
  conversation.scrollTop = conversation.scrollHeight;

  // 保存到状态
  assistantState.messages.push({ role, content, actions, timestamp: Date.now() });
}

// 格式化消息内容
function formatAssistantMessage(content) {
  // 支持 Markdown 格式
  return content
    .replace(/\*\*(.*?)\*\*/g, "<strong>$1</strong>")
    .replace(/`(.*?)`/g, "<code>$1</code>")
    .replace(/\n/g, "<br>");
}

// 显示输入中状态
function showAssistantTyping() {
  const conversation = $("assistant-conversation");
  const typing = document.createElement("div");
  typing.id = "assistant-typing-indicator";
  typing.className = "assistant-message assistant";
  typing.innerHTML = `
    <div class="assistant-message-avatar">AI</div>
    <div class="assistant-message-content">
      <div class="assistant-typing">
        <span></span><span></span><span></span>
      </div>
    </div>
  `;
  conversation.appendChild(typing);
  conversation.scrollTop = conversation.scrollHeight;
}

// 隐藏输入中状态
function hideAssistantTyping() {
  const typing = $("assistant-typing-indicator");
  if (typing) typing.remove();
}

// 处理操作按钮点击
async function handleAssistantAction(action) {
  switch (action.type) {
    case "create_task":
      // 创建任务
      showAssistantTyping();
      try {
        const response = await fetch("/api/coding-agent/submit", {
          method: "POST",
          headers: { "Content-Type": "application/json" },
          body: JSON.stringify(action.params),
        });
        const data = await response.json();
        hideAssistantTyping();

        if (data.status === "ok") {
          addAssistantMessage("assistant",
            `✓ 任务已创建: ${data.task.task_id}\n状态: ${data.task.display_status}`,
            [
              { type: "view_task", label: "查看任务详情", task_id: data.task.task_id },
              { type: "supplement", label: "补充信息", task_id: data.task.task_id },
            ]
          );
        } else {
          addAssistantMessage("assistant", `创建失败：${data.error}`);
        }
      } catch (error) {
        hideAssistantTyping();
        addAssistantMessage("assistant", `网络错误：${error.message}`);
      }
      break;

    case "view_task":
      // 跳转到任务详情
      switchView("tasks");
      selectTask(action.task_id);
      break;

    case "supplement":
      // 准备补充信息
      $("assistant-input").value = `补充信息：`;
      $("assistant-input").focus();
      break;

    case "open_workbench":
      // 打开工作台界面（已经在工作台中，无需操作）
      note("你已经在工作台界面中。", false);
      break;
  }
}

@app.route("/api/coding-agent/chat", methods=["POST"])
def coding_agent_chat():
    """处理 AI 对话助手消息"""
    try:
        data = request.json
        user_message = data.get("message", "").strip()
        context = data.get("context", {})

        if not user_message:
            return jsonify({"status": "error", "error": "消息不能为空"}), 400

        # 调用桥接层处理
        result = process_assistant_message(user_message, context)

        return jsonify({
            "status": "ok",
            "reply": result["reply"],
            "actions": result.get("actions", []),
            "task_id": result.get("task_id"),
        })
    except Exception as e:
        return jsonify({"status": "error", "error": str(e)}), 500


def process_assistant_message(message: str, context: dict) -> dict:
    """
    使用简单的意图识别和服务匹配

    实际实现可以调用 LLM 进行更智能的意图理解
    这里使用规则匹配作为快速原型
    """
    message_lower = message.lower()

    # 关键词映射到服务
    service_keywords = {
        "industry-research": ["研究", "调研", "市场", "行业", "竞争", "分析"],
        "government-proposal": ["政府", "政务", "合作", "方案"],
        "sales-review": ["客户", "复盘", "推进", "跟进"],
        "wechat-review": ["微信", "聊天", "会话"],
        "presentation-studio": ["ppt", "演示", "汇报", "幻灯片"],
        "weekly-deck": ["周报", "简报", "行动卡"],
        "pdf-import": ["pdf", "文档", "入库", "导入"],
        "office-document": ["文件", "文档", "方案书"],
    }

    # 匹配服务
    matched_service = None
    for service_id, keywords in service_keywords.items():
        if any(kw in message_lower for kw in keywords):
            matched_service = service_id
            break

    # 根据匹配结果生成回复
    if matched_service:
        service_names = {
            "industry-research": "客户与行业研究",
            "government-proposal": "政府合作方案",
            "sales-review": "客户推进与销售复盘",
            "wechat-review": "微信会话整理",
            "presentation-studio": "销售演示文稿工作室",
            "weekly-deck": "个性化销售行动简报",
            "pdf-import": "电子文档资料入库",
            "office-document": "销售文件与方案",
        }

        return {
            "reply": f"我识别到你需要使用 **{service_names[matched_service]}** 服务。\n\n任务内容：{message}\n\n确认创建任务吗？",
            "actions": [
                {
                    "type": "create_task",
                    "label": "确认创建",
                    "primary": True,
                    "params": {
                        "service": matched_service,
                        "project": "project-default",
                        "request": message,
                    },
                },
                {
                    "type": "adjust",
                    "label": "调整需求",
                    "primary": False,
                },
            ],
        }
    else:
        # 未匹配到服务，列出可用选项
        return {
            "reply": "我不太确定你需要哪个服务。以下是可用的服务：\n\n"
                     "• **客户与行业研究** - 研究客户、竞争对手或行业趋势\n"
                     "• **政府合作方案** - 准备政府项目合作方案\n"
                     "• **客户推进与复盘** - 跟进客户进展和销售复盘\n"
                     "• **PPT 工作室** - 制作销售演示文稿\n"
                     "• **销售行动简报** - 生成个人或总监汇报\n\n"
                     "请告诉我你具体需要什么？",
            "actions": [
                {"type": "services", "label": "查看全部服务", "primary": False},
            ],
        }

### 优势

1. **用户体验佳**：无需切换终端或 IDE，在熟悉的工作台界面完成所有操作
2. **视觉一致性**：复用现有设计系统，学习成本低
3. **渐进式增强**：不影响现有功能，命令行入口继续可用
4. **审批边界清晰**：明确标注哪些操作需要在任务中心审批

### 局限

1. **实现复杂度中等**：需要前后端协同开发
2. **意图识别简单**：初版使用关键词匹配，后续可接入 LLM 提升识别准确度
3. **对话上下文有限**：多轮对话需要额外状态管理

## 方案二：顶栏命令条增强（轻量替代）

### 设计思路

增强现有的底部命令条（`#quick-command`），添加"智能模式"开关。开启后，输入的内容会先调用意图识别 API，然后显示匹配的服务和参数预览。

### 优势

- 实现简单，复用现有 UI 组件
- 不需要新增页面和导航项
- 用户习惯改变最小

### 局限

- 对话历史不可见
- 多轮交互支持较弱
- 难以展示复杂的任务状态

---

## 推荐实施路径

### 第一阶段：核心对话界面（1-2 天）

1. 添加工具卡片和面板 HTML
2. 实现基础 CSS 样式
3. 实现前端消息渲染和发送
4. 实现后端简单的关键词匹配

### 第二阶段：服务集成（1 天）

1. 连接 `/api/coding-agent/submit`
2. 实现任务创建确认流程
3. 添加任务状态查询功能
4. 实现补充信息和调整方向

### 第三阶段：智能增强（可选）

1. 接入 LLM 进行意图识别
2. 支持多轮对话上下文
3. 添加任务推荐和主动建议
4. 集成语音输入（浏览器 Web Speech API）

---

## 技术栈

- **前端**：原生 JavaScript（与现有 app.js 一致）
- **后端**：Python Flask（与现有 server.py 一致）
- **桥接层**：`python -m agent_platform coding-agent ...`（复用现有）
- **样式**：CSS 变量和原有设计令牌（与 styles.css 一致）

---

## 数据流

```
用户输入
  ↓
前端 JavaScript (app.js)
  ↓
POST /api/coding-agent/chat
  ↓
后端处理 (server.py)
  ↓
意图识别 + 服务匹配
  ↓
调用 coding-agent 桥接层
  ↓
返回任务 ID 和状态
  ↓
前端渲染回复和操作按钮
  ↓
用户确认 → 创建任务
  ↓
跳转到任务中心查看进展
```

---

## 安全边界

1. **不绕过审批**：所有需要审批的操作仍在任务中心人工确认
2. **不直接调用 Pi**：只使用桥接层 API，不直接操作 `.pi/` 目录
3. **不存储敏感信息**：对话历史存储在内存，重启后清空
4. **权限一致**：与命令行入口享有相同的权限边界
