# 市场总监工作台使用说明

本文档面向首次使用本项目的市场总监，默认环境为 Windows、ChatGPT 桌面版个人账号、PowerShell 和本地 Python。项目根目录为：

```text
D:\PersonalWorkSpace\WorkFlow4Market
```

## 一、在 ChatGPT 桌面版中启用

### 1. 打开 Project

在 ChatGPT 桌面版中将 `D:\PersonalWorkSpace\WorkFlow4Market` 作为 Project 工作目录。Project 指令位于根目录 `AGENTS.md`，其中已经约定：

- 默认中文，面向 CEO 或政府客户正式、克制、结论先行；
- 明确区分“已证实事实”“分析判断”“待确认事项”；
- 行业和政策结论必须带来源、发布日期、访问日期和适用地域；
- 销售复盘看客户推进证据、承诺兑现、异议处理、下一步和管理支持，不按消息数量评价；
- 对外文件发送前必须人工确认。

### 2. 安装个人插件

仓库内的插件源码位于 `plugin/market-director-copilot/`。在 ChatGPT 桌面版的插件管理入口中安装个人插件 `market-director-copilot`（显示名：市场总监工作台）。如果桌面版尚未显示该插件，可将该目录作为本地个人插件源导入，或按当前客户端的 Personal Plugins 流程安装。

插件包含五个 Skill：

| Skill | 适用任务 |
| --- | --- |
| `research-frontier-markets` | 脑机、具身智能、数采等前沿资料研究 |
| `draft-government-cooperation` | 地方政府合作方案、项目边界和实施路径 |
| `review-sales-conversations` | 微信文字、图片、语音、视频复盘 |
| `manage-sales-pipeline` | 客户阶段、活动、销售和资源申请管理 |
| `build-market-decks` | PPT、模板管理和 CEO 周报 |

可直接使用的指令示例：

```text
请按 research-frontier-markets 整理本周脑机接口政策与产业动态，输出来源卡片，并区分事实、判断、待确认事项。
请基于知识库和客户场景起草某地政府合作方案，先给需求、资料清单和逐页大纲，再生成 PPT。
请同步已授权销售会话，复盘客户推进证据、销售承诺、异议和下一步动作。
请根据本周台账生成面向 CEO 的 8 页周报 PPT，并列出需要 CEO 决策的事项。
```

## 二、安装和检查本地 Python 环境

项目已使用 `.venv` 创建虚拟环境。首次使用或依赖发生变化时运行：

```powershell
Set-Location D:\PersonalWorkSpace\WorkFlow4Market
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

依赖包括：`faster-whisper`、PyAV、`python-pptx`、Pillow 和 PyYAML。首次转写时，`faster-whisper` 可能需要下载模型权重；CPU 默认使用 `small` + `int8`，速度和中文识别效果需要结合本机情况评估。

## 三、配置 WeFlow 微信复盘

### 1. 获取 Token

在 WeFlow 中打开 `设置` → `API 服务`，在 Access Token 区域点击生成按钮，复制生成的 Token，并启用 HTTP API 服务。默认地址为：

```text
http://127.0.0.1:5031
```

不要把 Token 写入 `config/market-director.json`、README、聊天内容或任何 Git 文件。

### 2. 保存 Token

推荐保存为 Windows 当前用户环境变量：

```powershell
[Environment]::SetEnvironmentVariable(
  "WEFLOW_ACCESS_TOKEN",
  "粘贴刚生成的Token",
  "User"
)
```

设置后重启 ChatGPT 桌面版。只在当前 PowerShell 窗口临时测试时，可以使用：

```powershell
$env:WEFLOW_ACCESS_TOKEN = "粘贴刚生成的Token"
```

### 3. 配置销售和会话

编辑 `data/sales/salespeople.json`：

```json
{
  "salespeople": [
    {
      "salesperson_id": "sales-001",
      "name": "张三",
      "weflow_session_id": "填写WeFlow会话ID",
      "active": true,
      "notes": "已取得内部授权"
    }
  ]
}
```

只填写已经获授权、允许进入 Project 处理的会话。未启用或缺少会话 ID 的记录不会同步。

### 4. 健康检查和增量同步

先确认 WeFlow 正在运行：

```powershell
Invoke-WebRequest http://127.0.0.1:5031/health
```

同步已启用会话（包括本机允许下载的媒体）：

```powershell
.\.venv\Scripts\python.exe plugin\market-director-copilot\scripts\weflow_sync.py --project .
```

只同步文字、跳过媒体下载：

```powershell
.\.venv\Scripts\python.exe plugin\market-director-copilot\scripts\weflow_sync.py --project . --no-media
```

同步结果写入 `data/weflow/normalized/messages.json`，运行状态写入 `data/weflow/state.json`。原始响应、媒体和缓存目录已在 `.gitignore` 中排除。

## 四、本地语音和视频转写

对单个音频或视频运行：

```powershell
.\.venv\Scripts\python.exe plugin\market-director-copilot\scripts\transcribe_media.py `
  .\data\weflow\media\会话目录\消息ID.mp4 `
  --output .\data\weflow\transcripts\消息ID.json `
  --frames-dir .\data\weflow\frames\消息ID
```

常用参数：

- `--model small`：默认中文模型；本机资源不足时可改为 `base` 或 `tiny`。
- `--device cpu --compute-type int8`：默认 CPU 配置。
- `--language zh`：中文；多语言素材可省略或调整。
- `--no-vad`：仅在 VAD 导致语音被误删时使用。
- `--max-frames 6`：视频最多提取 6 张关键帧供人工核验。

转写不清、画面不可读或说话人无法确认时，必须标记为待确认，不能用模型猜测补全。

## 五、维护业务台账

| 文件 | 用途 |
| --- | --- |
| `data/knowledge/source-register.csv` | 研究和政策来源登记 |
| `data/sales/customers.csv` | 客户、阶段、健康度和风险 |
| `data/sales/activities.csv` | 客户活动、证据和下一步 |
| `data/sales/resource-requests.csv` | 销售资源申请、截止时间和预期结果 |
| `data/sales/salespeople.json` | 销售人员与 WeFlow 会话映射 |
| `data/weekly/sample-weekly-input.json` | 周报输入格式示例 |

所有事实应保留证据路径或来源。客户阶段变化至少写明客户、证据、下一步、负责人和截止日期。

## 六、模板和 PPT

内置模板位于 `library/templates/`，目录由 `template-catalog.json` 管理。查看模板：

### 生产模式

当前 PPT Skill 支持两种模式：

- `native`：原生 PPT 文本、形状和图表，适合需要逐项编辑的周报、政府材料和数据型页面。
- `svg-first`：参考 Bento Grid 方法生成 1280×720 SVG 页面，适合视觉叙事、复杂信息架构和重点洞察页。SVG 封装进 PPTX 后是图片对象，不保证转换为原生文本框。

SVG-first 页面输入示例为 `data/weekly/sample-bento-input.json`。完整页面契约和布局规则见 `plugin/market-director-copilot/skills/build-market-decks/references/svg-bento-workflow.md`。

```powershell
.\.venv\Scripts\python.exe plugin\market-director-copilot\scripts\template_manager.py --project . list
```

切换当前模板：

```powershell
.\.venv\Scripts\python.exe plugin\market-director-copilot\scripts\template_manager.py --project . activate ceo-weekly
```

导入新模板（不会覆盖内置模板）：

```powershell
.\.venv\Scripts\python.exe plugin\market-director-copilot\scripts\template_manager.py --project . import `
  --id my-ceo-weekly `
  --name "我的CEO周报" `
  --kind weekly `
  --file "D:\资料\我的模板.pptx"
```

生成 CEO 周报：

```powershell
.\.venv\Scripts\python.exe plugin\market-director-copilot\scripts\build_weekly_deck.py `
  --input .\data\weekly\sample-weekly-input.json `
  --output .\outputs\market-weekly.pptx `
  --template ceo-weekly
```

周报默认 8 页，允许 7-10 页。生成前应先完成需求、资料清单、逐页大纲和来源核验；生成后检查页数、文本溢出、来源、字体、对比度和可编辑性。

验证 PPT 或 JSON：

```powershell
.\.venv\Scripts\python.exe plugin\market-director-copilot\scripts\validate_outputs.py `
  --pptx .\outputs\market-weekly.pptx `
  --json .\data\weekly\sample-weekly-input.json `
  --min-slides 7 `
  --max-slides 10
```

生成 SVG-first Bento Grid 页面：

```powershell
.\.venv\Scripts\python.exe plugin\market-director-copilot\scripts\build_svg_bento_deck.py `
  --input .\data\weekly\sample-bento-input.json `
  --svg-dir .\outputs\svg\bento-sample `
  --pptx .\outputs\bento-sample.pptx
```

校验 SVG 页面：

```powershell
.\.venv\Scripts\python.exe plugin\market-director-copilot\scripts\validate_svg_deck.py `
  --svg-dir .\outputs\svg\bento-sample `
  --min-pages 2 `
  --max-pages 10
```

SVG-first 模式必须同时人工查看 SVG 和 PPTX：检查中文断行、卡片层级、对齐、来源脚注和 PowerPoint 中的编辑方式。

## 七、每周 CEO 周报

已配置自动化：每周五 18:00（Asia/Shanghai）汇总当前 Project 的已记录工作，面向 CEO 输出 7-10 页周报，首页给出结论和需要 CEO 决策的事项。自动化不会对外发送文件或消息。

周报内容应至少覆盖：本周结论、关键指标、行业情报、销售漏斗、重点客户、销售/政府合作与资源问题、下周行动。示例输入可复制为新的周报 JSON，再由工作台生成 PPT。

## 八、常见问题

### Token 缺失

如果同步提示 `Missing WEFLOW_ACCESS_TOKEN`，确认：

1. WeFlow API 服务已启用；
2. Token 已写入“用户”环境变量，而不是只写入另一个终端；
3. 设置环境变量后已重启 ChatGPT 桌面版或重新打开 PowerShell。

### 没有同步到消息

确认 `salespeople.json` 中同时满足 `active: true` 和 `weflow_session_id` 非空，并检查会话 ID 是否对应允许处理的微信会话。

### 媒体无法下载

项目只下载 WeFlow 本机地址的媒体。外部 URL 会被标记为 `external_blocked`，需要在 WeFlow 本地导出或人工提供文件后再转写。

### PPT 需要修改或替换

优先复制或导入为新模板，保留内置模板以便恢复。对外发送前由用户人工检查事实、来源、数字口径和敏感信息。

## 九、数据与 Git 约定

以下内容不会提交：`.venv/`、WeFlow 原始数据和媒体、转写缓存、运行状态、日志、临时输出 PPT/PDF。提交前运行：

```powershell
git status --short
git diff --check
```

如果发现 Token、客户隐私或原始媒体出现在待提交文件中，应先移除并轮换凭证，再提交。
