# 业务资料库与三入口

本次将已确认的交互原型落入正式工作台，不迁移真实台账，不自动调用模型，不改动微信原库。

## 使用路径

- 对话：普通问答沿用临时、无工具聊天。输入“复盘客户进展”“制作 8 页 PPT”“解读文件”等明确任务，转为对应工作流表单；用户确认开始后才创建任务。识别错误可手动切换工作流。
- 资料库：销售、客户、项目、文件、微信会话。可搜索、按负责人和归档状态筛选，维护联系人、跟进、行动与里程碑，并关联原始资料。
- 工作进展：查看任务、审批与成果；尚未由智能核心接手的请求在刷新后仍显示。完成任务可从档案的“工作与成果”核对后保存一条本地行动，不自动提取建议为业务事实。
- 旧客户经营、投标、项目空间、定时任务等入口保留在“设置 → 其他工具与历史入口”。

## 数据与权限边界

本地扩展档案位于 `data/library/dossiers.sqlite3`。销售名册、客户台账与原生项目空间为只读投影，使用稳定来源编号关联，绝不按同名自动合并。负责人文字没有可靠编号时保留历史名称，用户自行关联人员。

扩展档案保存显式覆盖字段、联系人和记录；未改写的字段跟随来源更新。来源变化会提示核对，编辑其他字段不会清除来源警示。归档保留资料与记录，不删除原件。原生项目归档沿用现有逻辑，停用其定时任务；恢复不会擅自重新启用。

任务开始时由服务端冻结所选档案与最多 20 个文件引用。项目档案必须匹配实际任务空间，项目文件不能跨空间混用；文件单份上限为 32 MiB。本地文件保存内容 SHA-256，PDF 读取器对实际解析字节复核，变更后须新建任务；重启不会自动接受变更内容。带此背景的任务禁止通用文件读取/目录扫描，防止扩大选中范围。所选公开网页仍经过现有网络安全检查；普通公开研究检索保持原服务权限。

当前本地正文读取只支持受控 PDF；其他格式在本次背景中仅提供文件引用，不宣称已经解析。需要分析非 PDF 文件时先转换为 PDF。任务背景不是写入审批，正式台账、PPT 和其他正式产物沿用原来的 DAG 与人工确认。

微信入口提供“准备聊天记录（复制 → 解析副本）”，串联原有复制与解析；仍可分步操作、重试解析而不重新复制。现有静态副本、WAL、账号、密钥或进程取钥授权条件不变。

客户群、销售群分类由用户设置，不按群名推断；可关联销售、客户、项目，仅改变引用。筛选只作用于当前已加载会话；最终确认列出所选会话，并标明筛选外仍勾选的数量。微信任务仅附带单独确认的会话范围，不携带对话中选中的其他档案或文件。平台入口限制与私有数据目录校验保持不变。

## 验证与维护

自动化验证均使用临时合成数据、合成模型或本地测试服务；没有读取真实微信、CLI 登录文件或调用真实模型。

```powershell
npm run test:business-library
python -m unittest ui.test_server -q
npm run check:types
python -m agent_platform validate
```

可选浏览器验收需要本地 Playwright 与 Edge：配置 `A4M_BROWSER_PLAYWRIGHT` 为 Playwright 模块路径，然后运行 `npm run test:business-library-browser`。另有 `tests/ui-free-chat-browser.mjs` 和 `tests/ui-wxdecipher-browser.mjs` 覆盖既有聊天与微信复制/解析流程。

本地 SQLite 使用事务及快照版本防止并发覆盖；占用超时返回可重试错误，损坏数据拒绝覆盖。备份时先关闭工作台，再备份 `data/library/` 及原有业务数据；扩展档案只存引用，不能替代原始文件备份。旧程序忽略这份独立存储，不会把扩展档案误作正式台账。本次不自动升级、打包或发布安装包。
