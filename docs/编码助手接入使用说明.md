## 快速开始

### 1. 检查集成状态

```bash
python -m agent_platform coding-agent doctor
```

返回示例：
```json
{
  "status": "ok",
  "integration_ready": true,
  "workbench": {"ready": true, "status": "ok"},
  "hosts": {
    "codex": {"ready": true},
    "claude": {"ready": true}
  }
}
```

### 2. 查看可用服务

```bash
python -m agent_platform coding-agent services
```

当前支持的服务：
- `sales-review` - 客户推进与销售复盘
- `wechat-review` - 微信会话整理
- `industry-research` - 客户与行业研究
- `pdf-import` - 电子文档资料入库
- `government-proposal` - 政府合作方案
- `office-document` - 销售文件与方案
- `presentation-studio` - 销售演示文稿工作室
- `weekly-deck` - 个性化销售行动简报
- `bid-discovery` 到 `bid-retrospective` - 智能招投标全流程

### 3. 查看项目空间

```bash
python -m agent_platform coding-agent projects
```

### 4. 创建任务

将需求写入文本文件：
```bash
echo "请整理华为公司的最新进展" > request.txt
```

提交任务：
```bash
python -m agent_platform coding-agent submit \
  --service industry-research \
  --project project-default \
  --request-file request.txt
```

返回示例：
```json
{
  "status": "ok",
  "task": {
    "task_id": "request-24147f2882af",
    "status": "requested",
    "message": "任务已交给 Agent4Market 智能核心"
  }
}
```

### 5. 查询任务状态

```bash
python -m agent_platform coding-agent status --task-id request-24147f2882af
```

返回信息包括：
- 当前状态（requested/running/completed/failed）
- 当前执行节点
- 是否需要审批（requires_approval）
- 下一步动作

### 6. 补充信息或调整方向

向运行中的任务补充信息：
```bash
python -m agent_platform coding-agent message \
  --task-id request-24147f2882af \
  --mode supplement \
  --text "请重点关注云服务收入"
```

调整任务方向：
```bash
python -m agent_platform coding-agent message \
  --task-id request-24147f2882af \
  --mode redirect \
  --text "改为分析阿里云的竞争优势"
```

### 7. 打开工作台界面

```bash
python -m agent_platform coding-agent open
```

会在默认浏览器打开 http://127.0.0.1:8765

## 在 Claude Code 中使用

在 Claude Code 会话中，可以直接说：

```
/agent4market-sales-director

请帮我研究一下 2026 年人工智能芯片市场的竞争格局
```

Claude Code 会自动：
1. 识别这是 Agent4Market 任务
2. 选择合适的服务（如 industry-research）
3. 通过桥接层提交任务
4. 跟踪任务进展
5. 在需要审批时提示用户打开工作台

## 在 Codex CLI 中使用

在项目目录下运行 Codex：

```bash
codex
```

然后可以使用相同的方式：

```
使用销售总监助手，帮我准备一份关于智慧城市的政府合作方案
```

Codex 会调用 `agent4market-sales-director` skill 并通过桥接层与工作台通信。

## 审批边界

⚠️ **重要**：编码助手**不能**代替用户批准以下操作：

- 写入资料库或销售台账
- 生成正式 PPT、Word、Excel 文件
- 变更客户阶段
- 任何对外发送操作

当任务返回 `requires_approval: true` 时：
1. 编码助手会说明待确认事项
2. 用户需要在桌面工作台查看自然语言预览
3. 只有在工作台手动批准后任务才会继续

这个设计确保编码助手不会把"用户让我做任务"误解为"用户已批准具体写入内容"。

## 数据和安全边界

编码助手集成遵循以下边界：

✅ **允许**：
- 创建、查看、跟踪任务
- 补充信息和调整方向
- 查询服务、项目、任务列表
- 打开工作台界面

❌ **禁止**：
- 直接编辑 `data/`、`inputs/`、`outputs/`、`.pi/` 目录
- 调用工作台私有 HTTP 接口
- 读取未授权的微信会话
- 绕过审批机制自动批准操作
- 把客户资料、密钥带入公开搜索

## 故障排查

### 工作台未运行

```bash
python -m agent_platform coding-agent doctor
```

如果显示 `workbench.ready: false`，需要先启动：
- Windows：双击 `Agent4Market.exe`
- macOS：打开 `Agent4Market.app`

### Skill 哈希不匹配

```bash
python scripts/sync-coding-agent-skills.py
```

这会从 `integrations/coding-agents/` 重新同步到 `.claude/skills/` 和 `.agents/skills/`。

### 查看详细日志

工作台日志：
```bash
tail -f .pi/director-runtime/desktop-launcher.log
```

AI 核心日志：
```bash
tail -f .pi/director-runtime/ai-core.log
```
