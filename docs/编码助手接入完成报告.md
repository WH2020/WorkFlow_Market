## 架构说明

### 桥接层设计

```
Claude Code / Codex CLI
         ↓
  /agent4market-sales-director skill
         ↓
  python -m agent_platform coding-agent ...
         ↓
  HTTP API (127.0.0.1:8765)
         ↓
  Agent4Market 工作台
         ↓
  Pi 智能核心（受控 DAG 状态机）
```

### 审批边界

编码助手**可以**：
- 创建任务
- 查看任务状态
- 补充信息（`--mode supplement`）
- 调整方向（`--mode redirect`）
- 查询服务、项目列表
- 打开工作台界面

编码助手**不能**：
- 批准写入资料库/销售台账
- 批准生成正式文件（PPT/Word/Excel）
- 批准变更客户阶段
- 批准任何对外发送操作
- 直接编辑 `data/`、`inputs/`、`outputs/` 目录
- 绕过工作台直接调用 Pi

当任务需要审批时（`requires_approval: true`），必须在桌面工作台人工确认。

### 数据流

1. **任务创建**：
   - 编码助手 → 文本文件/stdin
   - 桥接层 → `POST /api/task-requests`
   - 工作台 → 受控 DAG 队列
   - Pi 核心 → 开始执行

2. **状态查询**：
   - 编码助手 → `GET /api/tasks`
   - 工作台 → 返回当前状态、节点、下一步

3. **消息传递**：
   - 编码助手 → `POST /api/tasks/{task_id}/messages`
   - 工作台 → 排队到任务上下文
   - Pi 核心 → 在安全边界内处理
