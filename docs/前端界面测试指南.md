## 测试步骤

### 1. 启动工作台

**重要：必须重启工作台才能加载新的前端代码**

```bash
cd <PROJECT_ROOT>
python -m ui.server
```

或者如果使用 Tauri 桌面应用，关闭并重新打开应用程序。

### 2. 打开设置页面

1. 在浏览器中打开 `http://localhost:5678`
2. 点击左侧导航栏的 **"设置"**
3. 向下滚动到 **"模型提供者"** 面板

### 3. 验证自动检测

页面加载后应该自动检测编码助手，检查：

- **Claude Code** 状态应显示：`已安装 (2.1.245 (Claude Code))`
- **Codex CLI** 状态应显示：`已安装 (codex-cli 0.149.1)`
- 如果未检测到，会显示 `未检测到` 或 `检测失败`

### 4. 测试提供者切换

**测试 Claude Code：**
1. 选择 **"Claude Code"** 单选框
2. 配置区域应自动展开
3. 可执行文件路径应显示：`<USERPROFILE>\AppData\Roaming\npm\claude.cmd`
4. 模型下拉框应包含：
   - Claude Opus 5 (最强推理)
   - Claude Sonnet 5 (平衡)
   - Claude Haiku 4.5 (快速)

**测试 Codex CLI：**
1. 选择 **"Codex CLI"** 单选框
2. 配置区域应自动切换
3. 可执行文件路径应显示：`<USERPROFILE>\.codex\...\codex.exe`
4. 模型下拉框应包含：
   - Claude Opus 5
   - Claude Sonnet 5

**测试 NewAPI 网关：**
1. 选择 **"NewAPI 网关"** 单选框
2. Claude Code 和 Codex CLI 配置区域应隐藏
3. 点击"保存提供者选择"应提示：**"请在下方 NewAPI 配置面板中配置网关地址和模型"**

### 5. 测试保存配置

**保存 Claude Code 配置：**
1. 选择 **"Claude Code"**
2. 选择模型：**"claude-opus-5"**
3. 点击 **"保存提供者选择"**
4. 应显示成功消息：**"Claude Code 已配置为模型提供者，重启应用后生效。"**
5. 面板顶部状态应更新为：**"Claude Code · Claude Opus 5 (最强推理)"**

**保存 Codex CLI 配置：**
1. 选择 **"Codex CLI"**
2. 选择模型：**"claude-sonnet-5"**
3. 点击 **"保存提供者选择"**
4. 应显示成功消息：**"Codex CLI 已配置为模型提供者，重启应用后生效。"**
5. 面板顶部状态应更新为：**"Codex CLI · Claude Sonnet 5"**

### 6. 测试重新检测

1. 点击 **"重新检测编码助手"** 按钮
2. 按钮文本应变为：**"检测中…"**
3. 检测完成后按钮恢复为：**"重新检测编码助手"**
4. 状态徽章应更新

### 7. 验证配置文件

检查配置是否正确保存：

```bash
cat .pi/director-runtime/model-provider.json
```

## 常见问题排查

### 问题 1：JSON 解析错误

**错误信息：** `Unexpected token '<', "<!DOCTYPE "... is not valid JSON`

**原因：** 工作台服务器未运行或返回了 HTML 错误页面

**解决方法：**
1. 确认工作台正在运行：`curl http://localhost:5678/api/health`
2. 重启工作台服务器
3. 清除浏览器缓存并刷新页面

### 问题 2：状态显示"检测失败"

**原因：**
- 后端 API 返回错误
- 编码助手不在 PATH 环境变量中

**解决方法：**
1. 在命令行测试：
   ```bash
   python -c "from agent_platform.model_provider import detect_coding_assistants; print(detect_coding_assistants())"
   ```
2. 检查 Claude Code 和 Codex CLI 是否安装
3. 打开浏览器开发者工具查看网络请求详情

### 问题 3：保存后状态未更新

**原因：** 前端没有重新渲染

**解决方法：**
- 刷新页面
- 重启工作台

### 问题 4：切换提供者后配置区域不显示

**原因：** JavaScript 事件监听器未绑定

**解决方法：**
1. 打开浏览器开发者工具检查控制台错误
2. 确认 `app.js` 已更新
3. 强制刷新页面（Ctrl+F5）
