# 桌面文档工具与许可证

独立 PPT 工具链只使用公开可审阅的软件，不调用 Codex Desktop 私有包或缓存目录。

| 工具 | 固定版本/来源 | 用途 | 许可证 |
|---|---|---|---|
| [PptxGenJS](https://github.com/gitbrent/PptxGenJS) | `4.0.1`，npm lockfile | 生成原生可编辑 PPTX | MIT |
| [PDF.js](https://github.com/mozilla/pdf.js) | `6.2.108`，npm lockfile | 读取 LibreOffice 生成的 PDF | Apache-2.0 |
| [@napi-rs/canvas](https://github.com/Brooooooklyn/canvas) | `1.0.7`，npm lockfile | 逐页 PNG 和预览拼图 | MIT |
| [JSZip](https://github.com/Stuk/jszip) | `3.10.1`，npm lockfile | 构建/检查 DOCX 与检查 PPTX Open XML、页数和 speaker notes | MIT / GPLv3 双许可；本项目按 MIT 使用 |
| [LibreOffice](https://www.libreoffice.org/about-us/licenses/) | 由 winget/Homebrew 或用户安装 | 将 PPTX、正式投标 DOCX 真实渲染为 PDF | MPL 2.0（并提供 LGPLv3+ 双许可） |
| [Node.js](https://nodejs.org/) | Windows 私有运行时固定 `24.19.0`，官方压缩包 | 运行 Pi、受控适配器和本地文档工具 | MIT；下载前核对官方 SHA-256 |
| [ripgrep](https://github.com/BurntSushi/ripgrep) | winget/Homebrew | Agent 项目内快速文本检索 | MIT / Unlicense |
| [fd](https://github.com/sharkdp/fd) | winget/Homebrew | Agent 项目内快速文件查找 | MIT / Apache-2.0 |
| [pi-provider-newapi](https://github.com/ttimasdf/pi-provider-newapi) | 设计参考，不随应用安装 | NewAPI 动态发现、端点判断与本地目录思路 | MIT |

LibreOffice 不复制到仓库，也不由 Agent 静默下载未知二进制文件。Windows 安装器只调用 winget 的 `TheDocumentFoundation.LibreOffice`，失败时可回退到 Chocolatey 的 `libreoffice-fresh`；macOS 安装器只调用 Homebrew Cask `libreoffice`。用户可以禁止自动安装并提前安装官方版本。

`pnpm-lock.yaml` 固定 Node 依赖及完整性哈希。更新任一生成或渲染依赖后，必须重新运行 Windows/macOS 的 `test:ppt-e2e`，真实生成 4 页 PPTX，并核验 PDF、逐页 PNG、notes 来源和 layout QA。

安装器拒绝使用 Codex 私有缓存目录中的 pnpm；Windows 优先使用系统/Corepack pnpm，缺失时可由 winget 安装 `pnpm.pnpm`，macOS 使用 Corepack、npm 或 Homebrew。依赖安装统一带 `--ignore-scripts`，不执行第三方包生命周期脚本；安装完成后必须通过原生 Canvas 加载和真实 PPT 端到端测试，不能用跳过测试代替脚本执行。

Windows 系统 Node 缺失或版本不符合要求时，安装器只从 `https://nodejs.org/dist/v24.19.0/node-v24.19.0-win-x64.zip` 下载，并要求 SHA-256 为 `57f71ab3652e797d84acddc79c81cc9ff1c6ddb2a1974cdb83f00fee9bff4c73`。文件解压到被 Git 忽略的项目私有 `runtime/node/`；启动脚本仅修改本次 Agent 子进程的 PATH，不修改系统 PATH。
