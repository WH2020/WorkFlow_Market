# 自由聊天

入口在左侧导航「自由聊天」。它用于问答、讨论想法和润色主动输入的文字；原「工具栏 → AI 对话助手」更名为「任务助手」，仍保留原来的服务识别和任务创建功能。

## 使用

1. 先在设置中配置模型，再进入自由聊天选择「对话模型」和思考强度。
2. Enter 发送，Shift + Enter 换行；生成期间可点击「停止生成」。
3. 可继续追问；切换工作台页面不清空对话。「新对话」会结束当前会话，并允许重新选择模型。

第一版不保存聊天记录到业务库或聊天文件。刷新、关闭页面或重启应用后开始新对话；页面退出通知丢失时，服务端闲置会话在 30 分钟后、下一次聊天请求到来时清理。每段最多完成 20 轮，每条输入最多 8000 字；较小模型还受上下文预算限制。失败或停止的轮次不会进入后续模型上下文，页面保留失败提示及输入草稿。

## 模型与边界

- 支持现有 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages API，以及 Windows 下已注册、校验过启动文件的 Claude Code / Codex CLI 后端。不得自动换供应商或回退到其他账户。
- 仅发送固定聊天说明、本段已成功完成的用户/助手文字和本轮输入。不附带客户、项目、任务、微信、文件、浏览器或其他业务上下文，不自动创建任务、调用工具、联网检索或提交审批。
- 单独使用无工具模型传输，不创建 Pi Agent 会话，不加载项目技能、扩展或历史会话。API 只读取所选供应商凭据；凭据更换、接收方或思考配置改变后，旧对话必须重开。凭据指纹只存在进程内存中。
- CLI 使用当前 Windows 用户的当前登录，沿用既有关闭原生工具、项目/用户定制和会话复用的启动参数。切换 CLI 登录账号后应新建对话。此处不是操作系统级文件沙箱，不能保证同用户 CLI 二进制在 OS 层没有文件读取能力。
- 每轮采用随机私有工作目录；新运行根是当前用户目录下的 `Agent4MarketFreeChat`，既有目录只验证权限，不修复或使用不安全目录。对话和凭据通过 stdin 传入，不放在命令行或配置文件中。
- 只接受同机、同 Windows 用户及登录会话的请求，并校验请求令牌和 JSON 类型。模型回复按纯文字显示，不执行 HTML，也不加载其图片或链接。
- 服务端最多同时生成 2 轮、缓存 8 段会话。请求超时 180 秒；回复文字上限 128 KiB，API 原始响应上限 2 MiB；HTTP 写入超时 5 秒。停止、超时和连接关闭会中止当前请求；Windows 进程树由 kill-on-close Job 管理。POSIX 暂不提供 CLI 自由聊天。

## 验证

所有模型验收均为合成数据；没有读取真实 CLI 登录、发送业务资料或实际调用收费模型。

- `python -B -m unittest tests.test_free_chat`：会话、接口、凭据轮转、并发取消、私有目录及进程清理；三种 API 和两种合成 CLI 均经过正式传输与 Windows 进程宿主。
- `node --test pi/tests/free-chat.test.ts`：接收方、禁止重定向、原始响应上限、无工具 CLI 参数与对话、取消和非法消息角色。
- `node tests/ui-free-chat-browser.mjs`：真实页面/HTTP/模型进程，使用独立无登录态 Edge 和本机合成服务；浏览器外网请求被阻止。覆盖多轮、键盘、停止/重试、认证错误、文字安全渲染、页面切换、刷新清空及窄窗口。
- `tsc --noEmit` 以及既有模型、HTTP 和请求头回归测试。

浏览器脚本复用已安装的 Playwright/Edge，可用 `A4M_BROWSER_PLAYWRIGHT`、`A4M_BROWSER_PYTHON` 和 `A4M_BROWSER_OUTPUT` 指定环境与验收输出。不能把这些合成结果表述为真实账号连通性验证。
