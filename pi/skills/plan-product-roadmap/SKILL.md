# 产品路线图

## 工作流

1. 明确规划周期、战略目标、不可变约束、团队容量和决策人。
2. 汇总候选机会及证据，比较用户价值、业务价值、战略匹配、成本、风险、时效和依赖。
3. 没有可靠数据时使用区间和情景，不伪造精确评分；记录评分依据和不确定性。
4. 形成 Now / Next / Later 路线图，给每项工作定义目标结果、进入条件、退出条件、负责人和关键依赖。
5. 检查容量超配、单点依赖、隐性维护成本、合规/安全门槛和被挤出的重要工作。
6. 输出推荐方案、备选方案、取舍、风险、需要管理层决定的事项和复盘时间点。

## 边界

- 路线图表达目标与选择，不承诺未经团队评估的精确日期。
- 优先级变化必须保留决策记录和影响范围。
- 资源不足时明确缩范围、延后或增加资源三类选择。
