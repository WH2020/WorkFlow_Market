# Agent 知识库

## 数据边界

- 现有研究来源从 Project 的 `data/knowledge/source-register.csv` 读取；其他业务数据由对应插件的数据命名空间管理。
- 原始文件保持原位，知识库只保存索引、来源、摘要、关系和可追溯位置，不静默改写原件。
- 实际客户、员工和未公开产品信息只保存在本地；公开仓库只提交 `.example` 模板。

## 读取

1. 按当前 Profile、任务、对象、时间和地域检索，记录本次知识快照的时间与范围。
2. 对每条信息保留稳定 ID、对象、陈述、状态、来源、证据位置、发布日期/发生时间、适用地域、有效期和访问范围。
3. 状态只能是“已证实事实、分析判断、待验证假设、未知信息”；模型摘要不能自动升级为事实。
4. 遇到冲突时并列保留，标注时间、地域、口径和来源差异，不覆盖较早记录。

## 更新

1. 从任务产物中只提取对未来任务可复用的事实、决策、实体关系、承诺、风险和经验。
2. 写入前重新读取目标记录，按稳定 ID 检查重复、版本变化和冲突。
3. 先生成拟新增、拟修订、保持不变和冲突清单；涉及客户阶段、人员评价、正式产品决策或对外承诺时必须人工确认。
4. 采用追加或带版本的替代关系，保留来源和历史；不得因周度原文清理而删除已确认的结构化证据链。
5. 返回知识快照、变更摘要、未解决冲突和下次复核时间。

## 质量门槛

- 每项正式结论都能回到来源或原始证据位置。
- 没有来源的模型推断只能写入“分析判断”或“待验证假设”。
- 不同 Profile 可复用公共知识，但只能读取其被授权的数据命名空间。
