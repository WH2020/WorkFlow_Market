# 0.20.2 应用更新入口与 Codex 模型目录补丁

补丁编号：`0.20.2-app-updates-20260910`。

这是累积的程序补丁，不是完整安装包，也不是自动安装器。它包含 17 个程序/说明文件、更新后的程序清单及补丁回执，包含之前的 Codex 模型目录修复，无需先应用旧补丁。

适用基线：尚未应用旧补丁的 `Agent4Market-0.20.2-portable`。基础程序清单摘要必须为 `7c945f7aa030f368afdee08a33e02a6fff364469998c59474648919cf88e9191`。已应用其他补丁或另行修改程序时，必须重新核对差异，不得直接覆盖。

## 新功能

- 左侧“检查更新”入口及“设置 → 应用更新”卡片。
- 默认启动时检查，应用打开期间约每 5 分钟检查 GitHub 正式版本；可以关闭自动检查或手动检查。
- 展示当前版本、新版提示、发布时间、更新说明、错误及最后检查时间。
- 用户确认后在系统浏览器打开发布页；不会自动下载、安装、覆盖或重启。
- 已有 Codex 模型目录及思考强度联动修复一并保留；`ultra` 仍因当前 Pi 能力限制而禁用。

发布源固定为 `WH2020/WorkFlow_Market`。2026-09-10 验证时公共 latest 接口返回 404，尚不能确认有可用的公开正式 Release；应用会明确显示更新源不可用，不会伪报“已是最新”。测试中的 0.20.3 是合成版本，不代表已经发布。

## 应用边界

必须先完全退出 Agent4Market 及智能核心。不能在运行中拖放覆盖，不能整体替换或删除安装目录。

应用前逐项核对 `hotfix-manifest.json` 的旧摘要和新摘要，备份清单内的旧程序文件，再进行程序替换和结果校验。原先不存在的文件仅允许 `agent_platform/cli_model_catalog.py`、`agent_platform/app_updates.py`；其他异常必须停止。新文件与程序清单不涉及数据迁移。

不得读取、复制或修改 `.pi/`、`data/`、`outputs/`、公司模板或 CLI 登录目录。保留原始 `runtime/portable-build.json` 历史记录，另写补丁回执。回退只恢复备份的程序文件，不动用户配置或业务数据。

本次不会修改已交付的原始 0.20.2 安装包、纯净载荷、旧 Codex 补丁或 0.20.1。第一次加入应用更新入口仍需上述一次程序更新；此后可以在应用内检测新版，但当前功能不包含就地升级。

详细行为、安全边界和开发验收命令见源码文档 `docs/应用更新.md`。
