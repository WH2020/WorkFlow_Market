# Agent4Market 0.20.2 · Windows x64 免安装版

## 直接启动

双击本目录的 `Agent4Market.exe` 即可。无需运行 Setup、安装 Python/Node 或以管理员身份启动。

交付目录为当前 Windows 用户目录下的 `Agent4Market-0.20.2-portable`（即 `%USERPROFILE%\Agent4Market-0.20.2-portable`）。它与安装版及旧版分开，使用自己的空白业务表、配置和运行数据；没有复制或迁移任何旧数据、模型密钥、微信内容或 CLI 登录文件。首次使用请到设置中配置模型。

请先关闭其他版本的 Agent4Market：工作台使用本地端口 8765，同一时间只能运行一份。关闭主窗口会回收本次启动的工作台和 AI 核心。

这是完整目录版，不是单文件 EXE。`.venv`、`runtime`、`node_modules`、`agent_platform`、`pi`、`ui` 等配套目录必须保留。目录中的 `INSTALL-NOTES.md` 介绍安装包，免安装版请以本说明为准。

## 依赖和功能范围

已包含 Python 3.11.9 x64、Node.js 24.19.0、pnpm 11.22.0、Pi 0.84.2 及应用依赖。

系统仍需 Git、ripgrep（`rg`）、`fd` 和 Microsoft Edge WebView2 Runtime；前三项须在系统 PATH 中。生成演示文稿另需 LibreOffice。可选语音模型资源、Claude Code / Codex CLI 程序及登录账号不在本目录内。

CLI 后端需要用户自行安装和登录受支持版本；检测到程序不代表账号可用。如果已有 CLI 暂存目录的权限不符合安全策略，CLI 模式会被安全检查拦截；打包不会修改该目录的权限。API 模式不经过该目录。CLI 首版仅支持文本，微信会话授权范围继续只允许 API 后端。

## 目录安全、备份与迁移

此目录已按本机当前 Windows 用户建立私有 NTFS 权限，无注册表登记、快捷方式或系统 PATH 修改。程序和业务资料使用同一个受保护的根目录。

免安装不等于可以放到任意共享目录运行。ZIP 不保存本版依赖的私有 Windows 权限；不要仅打 ZIP、解压后就假定可安全使用。移动目录、换盘或换电脑前先关闭应用并备份，迁移后必须重新验证目录及祖先路径的权限。不要通过管理员运行、删除私有运行标记或放宽安全检查绕过报错。

使用后需备份整个目录，尤其是 `data`、`.pi`、`outputs` 及 `library/templates/company`。删除目录也会删除其中的数据，本版没有自动迁移或自动备份功能。构建工具遇到已有同名目录会拒绝覆盖，也不会重设已有目录权限。

桌面 EXE 未签名，Windows 可能显示未知发布者提示；不要关闭系统安全保护。跨电脑、非 NTFS 介质和真实云端账号未包含在本机启动验收结论中。
