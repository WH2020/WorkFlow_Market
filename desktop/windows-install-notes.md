# Agent4Market 0.20.2 · Windows x64 安装说明

本版本加入可选 Claude Code / Codex CLI 模型执行后端，保留 API 模型供应商。CLI 只返回文本和工作台工具请求；任务状态、工具执行和用户审批仍由 Pi 工作台管理。

2026-09-10 首次公开发布的安装包已包含 Codex 模型目录修复和应用更新入口，无需另行应用仅适用于旧便携版的热补丁。此前本地交付的同版本安装包与本次公开包摘要不同，以正式 Release 中的 SHA-256 为准。

## 检查应用更新

左侧“检查更新”或“设置 → 应用更新”可查看当前版本、最新正式版本和更新说明。默认启动时检查，应用打开期间约每五分钟检查 GitHub 正式发布；可关闭自动检查或手动检查。网络错误或限流时会延后重试。

本功能只检测版本。打开发布页需要确认，不会自动下载、安装、覆盖目录或重启应用。首次公开版为 `0.20.2`，本机同版本应显示已是公开最新版本，不会为演示提示而虚报更高版本。

## 安装与启动

双击 `Agent4Market-0.20.2-Setup-x64.exe`，以当前普通用户安装，无需管理员权限。固定安装目录为当前 Windows 用户目录下的 `Agent4Market-0.20.2`。如果目录已存在，安装器会拒绝覆盖，包括空目录；请先检查其中的数据，不要直接批量删除。

安装不会迁移、读取或覆盖 0.20.1；不会读取微信聊天或 CLI 登录文件，也不会自动启动应用。安装后请关闭旧版本，再通过 `Agent4Market 0.20.2` 快捷方式启动。两版可分目录保留，但同时只能运行一个工作台（本地端口 8765）。

安装器会建立仅当前用户和 SYSTEM 可访问的私有目录，校验逐文件 SHA-256，并初始化空白业务表。不会携带开发机聊天、模型配置、密钥、业务数据或验收样本。内置人员表只含一条未激活的公开占位记录。

## 已包含与外部依赖

已包含 Python 3.11.9 x64、Node.js 24.19.0、pnpm 11.22.0、Pi 0.84.2，以及 Python/Node 应用依赖；不依赖系统安装的 Python 或 Node。Python 是固定版本应用运行时，不会跟随系统 Python 自动更新。

安装前需要本机的 PATH 中有 Git、ripgrep (`rg`) 和 `fd`，并已安装 Microsoft Edge WebView2 Runtime。安装器只检查，不会代装或修改系统 PATH。生成演示文稿另需 LibreOffice；语音模型等可选资源不在本包中。

Python 采用官方应用嵌入包，依赖随应用固定交付；关闭用户 site、环境路径和 `.pth` 启动扩展。相关机制见 [Python 官方文档](https://docs.python.org/3.11/using/windows.html#the-embeddable-package)。WebView2 安装检测依照 [Microsoft 官方文档](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/distribution)。

## 选择 CLI 后端

在设置中检测本机 CLI，选择 Claude Code 或 Codex CLI，并选择或填写你账号可用的模型 ID 后保存，再重启工作台。Codex 提供内置模型目录和思考强度联动；目录不代表账号权限验证，当前 Pi 不支持的 `ultra` 仍禁用。原有 API 配置会保留。CLI 需由你自行安装并登录；本包不包含 CLI 程序、登录账号或订阅。

首版已验证的原生协议版本为 Claude Code 2.1.245、Codex CLI 0.149.1；不支持的版本会被拒绝，不会静默回退到 API。检测到程序不等于已验证账号登录或额度。

CLI 首版只支持文本任务；微信会话授权范围仍只允许走 API 后端。开发验收不调用真实云端模型，不验证你的账号、订阅或计费。CLI 用量依其账号规则计费，工作台显示的零成本占位不是免费承诺。

## 卸载、重装与数据

通过 Windows 应用列表或目录中的 `Uninstall.exe` 卸载。卸载仅删除安装清单中未改动的程序文件；保留 `data`、`.pi`、`outputs`、公司模板、修改过或被占用的文件，以及私有运行标记和安装清单。不会递归删除版本目录，不会终止应用进程。

由于保留数据，同版本再次安装仍会拒绝该目录。请先自行备份并处理旧目录，或使用不同版本；本版本不提供自动数据迁移或原地修复。

安装程序尚未代码签名，Windows 可能显示未知发布者/SmartScreen 提示。请核对交付的 SHA-256；不要关闭系统安全保护。

## 构建及验收边界

安装器基于 NSIS 3.11，使用普通用户权限。提供 `/S /VERIFY=<32位小写十六进制ID>` 供构建验收：只在版本专用测试目录安装，不创建快捷方式或卸载注册表项；不能据此指定任意目录。

交付前的具体执行结果记录在源码项目的 `docs/Windows-0.20.2-安装包验收.md`。跨机器/全新 Windows、真实账号登录和真实云端任务不属于本机离线验收结论。
