# 0.20.2 Codex 模型目录热修复

修复编号：`0.20.2-codex-catalog-20260910`。

本包只含 15 个程序/说明文件和更新后的程序清单，不是完整安装包。适用于已交付的本机 `Agent4Market-0.20.2-portable`；不更新原始安装器、纯净构建载荷或旧版 0.20.1。

## 修复内容

- 自动查询 Codex CLI 的模型目录，按模型列出并保存支持的思考强度。
- 任务顶部选项随模型联动；所选强度精确传给 Codex，不静默改档。
- 任务恢复和受控子任务保留创建时的强度；目录失败时保留旧配置。
- 保留已有 API/CLI 实例、登录方式、用户配置、任务和业务数据。

目录来自隔离的 CLI 查询，未读取真实登录，也不证明账号权限或剩余额度。Pi 0.84.2 尚不能表示的 `ultra` 会显示但禁用。Claude 本次仍手动填写模型 ID。

## 应用前提

请先完全退出 Agent4Market，包括智能核心。不要在运行中直接拖放覆盖，也不要把整个目录替换或删除。

应用时须核对 `hotfix-manifest.json` 中每个文件的旧摘要，先备份这些程序文件和程序清单，再替换并核对新摘要。新文件只允许清单中原先不存在的 `agent_platform/cli_model_catalog.py`。已有程序若被另行修改，或目录权限不安全，应停止，不修复权限、不覆盖用户修改。

本包不包含配置/业务数据迁移。应用操作不得读取、复制或修改 `.pi/`、`data/`、`outputs/`、公司模板及 CLI 登录目录。原始 `runtime/portable-build.json` 作为历史构建记录保留，另写热修复回执。回退只恢复已备份的程序文件，不动用户配置和数据。

应用后重新打开原来的 `Agent4Market.exe`，进入“设置 → 模型提供者 → Codex CLI”，等待目录加载，选择模型与强度后保存，再重启智能核心。历史手填的模型不会自动换成另一个模型。
